# Data

Everything here is either downloaded (FLEURS), generated by a script, or
recorded by you. Audio is not produced by the ASR model.

## Layout

```
data/
  audio/fleurs/           generated by scripts/prepare_dataset.py
  audio/own/              your own recordings (list below)
  manifest.csv            checked-in sample of 12 FLEURS clips (source=fleurs)
  manifest_fleurs.csv     generated by scripts/prepare_dataset.py
  manifest.example.csv    empty-row example of the manifest format
  prompts.example.json    neutral sentence per language for initial_prompt
```

Manifest columns are `audio_path`, `reference`, `language` (optional) and
`source` (optional). Audio paths are relative to the manifest file. A row without
`source` is reported as `unspecified`, and results are never merged across
sources.

## Own recordings

Target: **6 clips per language for Hindi and Telugu**, each **5 to 20 seconds**.

Record yourself reading a written sentence aloud, so the text you read is the
reference. Pick sentences in the language and script you want to test, and keep
the written text exactly as you read it (punctuation included).

Do **not** create the reference transcript by running an ASR model on your
recording. That is circular: the evaluation would then score the model against
itself.

### Steps

1. Choose 6 Hindi sentences and 6 Telugu sentences. Write them down in the
   correct script (Devanagari, Telugu). Vary sentence length and vocabulary, but
   do not edit the text after recording.
2. Record one file per sentence in a quiet room, normal speaking pace, about an
   arm's length from the microphone. The phone or laptop microphone is fine.
   - Windows Voice Recorder saves `.m4a`, which the service accepts.
   - Audacity (Windows) can save `.wav` if you prefer.
3. Save the files under `data/audio/own/`, for example:

   ```
   data/audio/own/hi_01.m4a
   data/audio/own/hi_02.m4a
   ...
   data/audio/own/te_01.m4a
   ...
   ```

   Use names without spaces.
4. Create `data/manifest_own.csv` with Notepad (save as UTF-8). Keep the text in
   the original script. The snippet shows 2 of the 6 rows per language for
   brevity:

   ```csv
   audio_path,reference,language,source
   audio/own/hi_01.m4a,यहाँ आपका पहला हिंदी वाक्य है।,hi,own
   audio/own/hi_02.m4a,यहाँ आपका दूसरा हिंदी वाक्य है।,hi,own
   audio/own/te_01.m4a,ఇక్కడ మీ మొదటి తెలుగు వాక్యం ఉంది.,te,own
   audio/own/te_02.m4a,ఇక్కడ మీ రెండవ తెలుగు వాక్యం ఉంది.,te,own
   ```

   Quote a reference if it contains a comma.
5. Run the evaluation on it:

   ```powershell
   .\.venv\Scripts\python.exe -m scripts.evaluate --manifest data/manifest_own.csv --model-sizes base small --prompts-json data/prompts.json
   ```

### Read speech is not spontaneous speech

Reading a prepared sentence is easier than spontaneous conversation: the
speaker knows the text, speaks more clearly and there are fewer hesitations.
Scores on read speech are therefore usually better than real-world usage, and
they are not directly comparable to spontaneous-speech benchmarks. Report the
source whenever you quote a result.
